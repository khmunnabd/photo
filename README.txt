KHALED HASAN MUNNA — PHOTO PORTFOLIO
1. Extract this ZIP.
2. Upload the contents of this folder (index.html, assets/, README.txt) to your GitHub repository.
3. Keep index.html at the repository root.
4. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. The navigation links are same-tab links. WhatsApp/social links are not included on this page.
6. To add or replace photos, upload them into assets/ and add another <figure class="tile"> in index.html.
